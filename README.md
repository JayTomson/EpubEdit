# EpubEdit

Android-приложение для удобного редактирования и управления электронными книгами. Позволяет импортировать файлы в форматах EPUB и FB2, вносить изменения в текст, добавлять новые главы и экспортировать результаты обратно в валидный EPUB.

## Ключевые возможности

### Умный импорт
- Полная поддержка файлов `.epub`.
- Автоматическая трансляция `.fb2` в универсальный формат "на лету".
- Точный разбор структуры книги: извлечение оглавления (`nav.xhtml`, `toc.ncx`), метаданных, обложек и медиафайлов.

### Удобный редактор
- Редактирование текста организовано по отдельным блокам (абзацам и изображениям) для упрощения процесса.
- Полный контроль над структурой книги: меняйте главы местами, удаляйте ненужные или создавайте новые.
- Поддержка inline-иллюстраций, растровых картинок и векторной SVG-графики.

### Продвинутая статистика
- Встроенный анализатор текста показывает детальный подсчёт слов и символов как для отдельной главы, так и по всей книге в целом.
- Корректная работа с кириллицей, латиницей и составными словами (например, `как-то`, `it's`). HTML-теги не учитываются в статистике, что дает максимально точные цифры.

### Отличный экспорт
- Ваши изменения бережно упаковываются обратно: на выходе получается чистый и готовый к повседневному чтению или публикации `.epub` файл со всеми картинками и исходными метаданными.

## Сборка и установка

Вам понадобится **Android Studio** (рекомендуется последняя стабильная версия) и Android SDK 24+.

1. Склонируйте этот репозиторий:
   ```bash
   git clone https://github.com/ваш-юзернейм/EpubEdit.git
   cd EpubEdit
   ```
2. Откройте директорию проекта в Android Studio и дождитесь успешной синхронизации Gradle.
3. Нажмите `Run` в IDE, либо соберите APK через терминал:
   ```bash
   ./gradlew assembleDebug
   ```
   *Готовый тестовый APK можно будет найти по пути `app/build/outputs/apk/debug/app-debug.apk`.*

## Как это устроено (Стек)

Проект написан на **Kotlin** с соблюдением принципов чистой архитектуры (Clean Architecture) и использованием современных инструментов Android-разработки:

- **Интерфейс**: Jetpack Compose, Material 3 
- **Навигация**: Navigation Compose
- **Архитектура**: MVVM (AndroidViewModel, StateFlow, Coroutines)
- **Хранение данных**: Room (SQLite)
- **Отрисовка изображений**: Coil

Каталог `util/` содержит ядро работы с форматами: здесь происходят основные манипуляции с DOM и XML, парсинг оглавления EPUB и конвертация FB2.
